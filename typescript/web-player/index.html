oTAPE Web Player

An embeddable player for oTAPE 1.0 cassettes. Drop an .otape file on the player, or pick an example.

Embed it

<script type="module" src="otape-player/register.js"></script>
<otape-player src="night-drive.otape" droppable></otape-player>

Keyboard: K play/stop · J rewind · L fast forward · F flip
